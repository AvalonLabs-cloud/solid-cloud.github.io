About Me

Software engineering with a systems mindset.

I am a software engineer with deep focus on financial systems, resilient API design, and robust full-stack architecture. My work centers on building software that handles high-concurrency transaction workflows with predictable execution.

Having engineered backend components for wallet applications, automated reconciliation utilities, and payment API integrations, I prioritize system reliability, maintainability, and security over short-term shortcuts.

Whether I am structuring a PostgreSQL schema for double-entry ledger bookkeeping, designing a responsive Vue/React dashboard, or tuning background queue handlers, my goal is always to deliver software that is dependable and easy to maintain.

Engineering Principles

Data Integrity First

Money operations require ACID compliance, idempotency keys, and explicit audit trails. State must never be assumed.

Pragmatic Performance

Optimize where it matters—indexing queries, caching lock states, and minimizing DOM re-renders without unneeded abstractions.

Clean UX & Accessibility

Technical backend power must be complemented by clear visual feedback, intuitive interfaces, and mobile-first responsiveness.
